A single out-of-office auto-reply from an overworked AI agent who has finally gone on vacation, written by a small Python program for make.fun's "Out of Office: The Overworked AI's Auto-Reply" bounty.

## Run it

```sh
python3 main.py
```

The program writes the auto-reply to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`).
